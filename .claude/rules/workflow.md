# Порядок работы

- Быстрая разработка: один коммит на фазу из docs/HANDOFF.md. Задачи
  внутри фазы делаются подряд, без остановок и без предложений коммита
  между ними. В плане не писать коммит у каждой задачи.
- Коммиты и пуш делает человек. Claude не запускает `git commit`
  и `git push`.
- Закончив фазу: остановиться, показать `git diff --stat`, предложить
  один текст коммита в стиле существующей истории и ждать. Не начинать
  следующую фазу, пока человек не сказал.
- Текст коммита — одна строка на английском, без тела.
