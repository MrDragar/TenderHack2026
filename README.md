# Tender Hack Казань 2026

Кейс «Автозаполнение ключевых характеристик в СТЕ». Пользователь описывает товар
своими словами, а сервис находит конечный код КТРУ, заполняет характеристики, показывает,
как сужался выбор кодов, и объясняет каждую правку.

## Запуск с нуля

1. Установить зависимости:

   ```bash
   uv sync
   ```

2. Распаковать архив организаторов «Казань 2026.zip» в `data/raw/`, внутри него
   распаковать архив КТРУ и собрать справочник `data/processed/ktru.json`. Данные
   организаторов в git не лежат, их берём у команды.

   ```bash
   unzip "data/raw/Казань 2026.zip" -d data/raw
   unzip "data/raw/Казань 2026/КТРУ/КТРУ xml.zip" -d "data/raw/Казань 2026/КТРУ"
   uv run python scripts/build_ktru_actual.py
   ```

   Позиции КТРУ группируются по названию. Для каждого названия сохраняется конечная
   позиция с максимальным числовым суффиксом кода; ОКПД2 в выборе версии не участвует.

   Характеристики портала собираются со вторых листов файлов `Одежда.xlsx`,
   `Мебель.xlsx` и `Инструменты.xlsx` из `raw_data/`:

   ```bash
   uv run python -m scripts.build_portal
   ```

   Результат появится в `data/processed/portal.json`. Загрузчик возвращает контракт
   `ref.Portal`:

   ```python
   from scripts.dataloader import load_portal

   portal = load_portal()
   ```

   Ключи JSON это названия из колонки «Конечная категория ПП», значения это списки
   характеристик этих категорий. Сборщик склеивает перенесённые Excel хвосты, удаляет
   значения вида `[не найдено значение ID: ...]`, объединяет дубли названий и выбирает
   наиболее частые тип и единицу характеристики внутри каждой категории. Значения,
   которые Excel необратимо преобразовал в даты, не включаются.

3. Прогнать текст через пайплайн, результат печатается как JSON:

   ```bash
   uv run python -m pipeline.run "Стол письменный деревянный, столешница ЛДСП 22 мм"
   ```

   Из кода: `from pipeline.run import run`, затем `run(text)`.

4. Прогнать эталонный набор и посмотреть долю верных ответов и список ошибок. Набор
   `data/eval/gold.json` собран из данных организаторов, его тоже берём у команды.

   ```bash
   uv run python -m scripts.measure
   ```

5. Запустить веб-интерфейс и открыть http://localhost:8000. Порт можно передать
   аргументом.

   ```bash
   uv run python -m web.server
   ```

## Перед слиянием

```bash
uv run ruff check . && uv run ruff format --check . && uv run ty check
uv run pytest
```

## Где что

| Где | Что |
|---|---|
| contracts/ | типы данных и сигнатуры шагов, описание в contracts/README.md |
| pipeline/ | шаги: кандидаты, характеристики, сужение; run соединяет их |
| web/ | сервер и страница подбора кода |
| scripts/ | сборка и загрузка справочников КТРУ и портала |
| tests/ | тесты |
| docs/task.md | задача, критерии, ограничения, что сдаём |
| docs/data.md, docs/data-findings.md | устройство данных и выводы из них |
