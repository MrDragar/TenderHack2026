# UI-кит Портала поставщиков: выжимка для фронта

Всё снято через API Figma из
[UI-кита](https://www.figma.com/board/G64ZNZOpvILbIPYx8XVbxO/Portal-Postavshikov-(catalog)?node-id=1-1238&node-type=FRAME&t=3Rn0CFnDsfbnyUAY-0):
цвета, шрифты, размеры компонентов, иконки. По этим файлам можно верстать без Figma.

| Что | Где |
|---|---|
| Цвета, шрифты и готовые классы компонентов | tokens.css, подключить первым |
| Картинки компонентов 1:1 для сверки | screens/ |
| Иконки SVG по разделам кита, 340 штук | icons/<раздел>/ |
| Витрина всех иконок с именами файлов, открыть в браузере | icons/index.html |
| Логотип «Портал поставщиков» | icons/logo/portal_logo.svg |
| Целые страницы кита в масштабе 0,5: цвета, шрифты, кнопки, уведомления, попапы | screens/frames/ |


## Общий вид
- Фон страницы Pale Blue #E7EEF7, содержимое на белых блоках без скруглений.
- Кнопки, поля, таблицы и плашки прямоугольные. Скругление есть только у тегов (15px),
  круглых кнопок пагинации и полосок прогресса.
- Шапка белая, высота 80px, тень `0 10px 30px rgba(38,75,130,.1)`, слева логотип.
- Сетка 1280: 12 колонок по 56px, промежуток 24px. На 1600 колонки по 88px.
- Шрифт Open Sans, везде. Основной текст 14px/18px, подписи полей 16px полужирный.
- Попапы белые, тень `0 11px 70px rgba(38,75,130,.2)`, поля по бокам 88px. Ширины
  648, 1096 и 1336px.

## Компоненты
Все размеры в пикселях. Картинка каждого в screens/, вырезана из страниц кита в масштабе 0,5, для сверки, не для пиксель-в-пиксель.

**Кнопки** (button_white.png, button_red.png, button_disabled.png)
- Высота 48, отступы по бокам 20, текст 16 полужирный, между иконкой и текстом 10.
- Белая: фон белый, рамка Gray Blue 1px, текст Main Blue. При наведении рамка Main Blue 40%.
- Красная, главное действие: фон Red, текст белый. При наведении затемнение чёрным 10%.
- Неактивная: фон Pale Blue, текст чёрный 50%, без рамки.
- Ссылка-кнопка: текст Main Blue 16 полужирный, справа стрелка arrow_gray_right 12px.

**Поля ввода** (field.png, field_label.png, dropdown.png)
- Высота 48, текст внутри с отступом 15, 14px. Плейсхолдер Pale Black.
- Основной вид в формах: фон Pale Blue, без рамки.
- Поле поиска на белом фоне: фон белый, рамка Gray Blue, текст 16px.
- Подпись над полем: 16 полужирный, Black, отступ до поля 5. Необязательное поле:
  после подписи серым курсивом «(необязательно)».
- Выпадающий список: то же поле, справа стрелка arrow_gray_down 12px цвета Gray.

**Ошибка поля** (tooltip_required.png, status.png внизу)
- Рамка поля Red 1px, фон белый.
- Над полем справа красный тултип: фон Red, белый текст 14px, отступы 3 и 9, снизу
  уголок 11px. Текст «Поле обязательно для заполнения».

**Теги** (tag.png, tags_field.png)
- Высота 24, скругление 15, фон Main Blue, белый текст 14px, отступ слева 11.
  Справа белый крестик 10px.
- Поле со списком тегов внутри: фон Pale Blue, теги в строку с промежутком 8.
  В ките так показан список «Существующие характеристики: Ширина упаковки (миллиметр),
  Вес (грамм)».

**Поле значения с единицей** (field_with_unit.png)
- Подпись «Ширина упаковки, миллиметр», под ней поле со значением «120», справа крестик
  30px для удаления.

**Уведомления** (info_blue.png, info_red.png, info_dark.png)
- Высота 60, иконка «!» в круге 24px слева с отступом 20, текст 16/24 через 20 от иконки.
- Нейтральное: фон Pale Blue, текст и иконка Main Blue.
- Ошибка: фон Red 5%, текст и иконка Red.
- Тёмное: фон Dark #364051, белый текст, крестик справа.

**Плашка проверки формы** (notification_ok.png, notification_required.png)
- Белая полоса на всю ширину, слева иконка и текст 18px, справа кнопки.
- Всё заполнено: зелёная галочка, «Все необходимые поля заполнены», главная кнопка активна.
- Не хватает: красный «!», «Заполните все обязательные поля», главная кнопка неактивна.

**Статусы** (status.png)
- Капс 12px жирный, разрядка 1px, слева точка 8px того же цвета.
- Цвета по смыслу: Main Blue в работе, Green готово, Orange ожидает, Red отказ или
  ошибка, Gray неактивно.

**Таблица** (popup_chars.png, spec.png)
- Шапка: фон Pale Blue, высота 48, текст 14px чёрный 50%.
- Строки: текст 14/22, отступ слева 20, снизу линия Gray Blue 1px.
- Ячейка с ошибкой: см. popup_compare.png, розовый фон и красный текст.

**Табы** (tabs.png)
- Капс 18 жирный, разрядка 1px. Активный Main Blue с полоской снизу 3px, остальные Gray.

**Шаги** (steps_side.png, steps_numbers.png)
- Вертикальные шаги слева: круг 52px с иконкой, рядом капс-заголовок шага, под ним
  подпункты с маленькими радиокнопками. Активный шаг залит Main Blue, остальные белые
  с рамкой чёрный 20%.
- Нумерованные шаги в строку: круги 52px, пройденные Red с белой цифрой, следующий
  бледный с пунктирной рамкой Main Blue, между ними линия.

**Полоска совпадения** (match_bars.png)
- Подпись 12px «Совпадение 75%», под ней полоска 6px, скругление 7, цвет Sea Dark,
  фон Sea Dark 30%. Вариант с подписью «Совпадение 100% (13/13 характеристик)».

**Пагинация** (pagination.png)
- Круглые кнопки 40px, белые с рамкой Gray Blue, текущая страница залита Main Blue.

**Шапка и подвал** (header.png, footer.png)
- Шапка 1280×80: логотип 179×39 с отступом 28, дальше «Меню», ссылки 12px Main Blue
  с иконками 30px.
- Подвал: фон Pale Blue, ссылки 12px Main Blue.


## Что взять для нашей страницы
Готовые куски кита, которые прямо ложатся на наши блоки из docs/front.md:

| Наш блок | Что из кита |
|---|---|
| Шапка | header.png, логотип icons/logo/portal_logo.svg |
| Поле описания товара | поле с подписью на Pale Blue (field_label.png), кнопка «Подобрать» красная |
| Категория | статус с точкой Main Blue или тег |
| Сужение кодов | вертикальные шаги (steps_side.png) и полоска совпадения: «осталось N кодов» |
| Таблица характеристик | таблица из попапа «Добавление характеристик в СТЕ» (popup_chars.png): характеристика, значение, единица |
| Источник характеристики | статус с точкой: КТРУ Main Blue, Портал Sea Dark, Новая Orange |
| Ошибка в значении | розовая ячейка из popup_compare.png и тултип «Поле обязательно для заполнения» |
| Правка значения | поле значения с единицей (field_with_unit.png) |
| Код найден | плашка «Все необходимые поля заполнены» (notification_ok.png), код стилем H3 |
| Нужно уточнение | нейтральное уведомление (info_blue.png), варианты белыми кнопками |
| Не хватает обязательных | плашка «Заполните все обязательные поля» (notification_required.png), список тегами |
| Не нашли | уведомление-ошибка (info_red.png) |
| Ошибка сервера | тёмное уведомление (info_dark.png) |
